# guumana99.github.io

「ポケット庭園（ポケ庭）」の紹介サイト（GitHub Pages のユーザーサイト）。開発者 MANA99。

| ファイル | 内容 |
|---|---|
| `index.html` | トップ（スマホ向け 1 ページ） |
| `terms.html` | 利用規約 |
| `style.css` | 見た目（アプリの配色：ベージュ・こげ茶） |
| `images/` | アイコンとストアのスクリーンショット（縮小したもの） |
| `.nojekyll` | Jekyll を通さず、置いたファイルをそのまま出す |

プライバシーポリシーは https://guumana99.github.io/privacy-policy_pocketgarden/ （別のリポジトリ。Play に登録済みの URL）にリンクしている。

## サイトの一番上に置くファイル

ドメインの一番上（`https://guumana99.github.io/<ファイル名>`）に出したいファイルは、このリポジトリの一番上にそのまま置いてコミットする。

- `app-ads.txt`（AdMob）：パブリッシャー ID をもらってから作る。1 行の形は
  `google.com, pub-0000000000000000, DIRECT, f08c47fec0942fa0`
- TikTok の URL 確認用のファイル：渡されたファイル名・中身のまま置く。
